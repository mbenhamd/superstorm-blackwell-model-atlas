## Changes that affect a KServe runtime

The v0.5.22 → v0.5.23 change set is the same as in the [November 6 release comparison](sglang-v0523-upgrade.md). Three release differences bear directly on upgrades under KServe.

- **DeepSeek V4 and V4.1 chat and tools.** The engine adopts `deepseek-recipe` 0.2.0. Stream consumers must assemble tool-argument fragments, and V4 numeric reasoning-effort requests receive HTTP 400. Compare the gateway's streaming, template and tool-call contract before shifting traffic. ## Evidence scope

The first pass checked release/tag metadata, source at the two commits, recipe cells, the engine and third-party recipe provenance, plus registry and wheel publication records. The second pass tested inclusion against ancestry, distinguished cookbook verification labels from CI definitions and compared the worker's emitted settings with the original workload. In particular, a merged cookbook references an older engine image, the 1017 B300 cells retain an explicit validation gap, and the Mistral processor merge has a different code path from NVFP4 weight loading. No B300 runtime, weights, image layers or installed cluster were tested.
